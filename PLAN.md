# Zuma — план команды

## Идея

Zuma — игровой прототип для мониторинга самочувствия и когнитивных показателей астронавтов. Приложение на Godot помогает пройти короткие задания на реакцию и память, заполнить опрос, просмотреть историю и подготовить отчёт. Пульс планируется получать с совместимых умных часов; локальная модель может объяснять рассчитанные результаты.

Результаты мини-игр не являются диагнозом. Источники, ограничения и синтетические данные указываются явно.

## Архитектура

- Godot 4.7.2 / GDScript: игровой интерфейс и мини-игры.
- Локальный сервер Go: API, сохранение, расчёты, отчёт и адаптер модели.
- SQLite — предлагаемый вариант локального хранения; решение команды можно изменить.
- Часы: участник исследует API/SDK конкретного устройства и передачу измерений на сервер. Совместимость не подтверждена.
- Локальная модель: интеграция зависит от конкретной модели и среды запуска. Числовые расчёты делает код; модель не должна выдумывать данные или ставить диагноз.
- Интернет для локального сценария не обязателен. Отправка удалённому специалисту — отдельный последующий этап.

Статус: создан только стартовый проект Godot. Сервер, игры, часы и модель пока не реализованы.

## Роли

1. UI/UX-дизайнер: макеты, цвета, шрифты, компоненты, отчёт.
2. Godot-разработчик интерфейса: экраны, переходы, анимации, запросы к API.
3. Godot-разработчик мини-игр: реакция, память, результаты.
4. Go-разработчик: API, хранение, расчёты, отчёт, модель.
5. Интеграция часов: API/SDK, пульс, передача на сервер, обработка отключений.
6. Координация, исследование и тестирование: источники NASA, тексты, проверка, презентация и подача.

## Минимальный сценарий

Опрос → измерение пульса (реальное или явно обозначенное синтетическое) → игры → сохранение → отчёт → объяснение модели. Если часы или модель недоступны, основной сценарий должен продолжать работать; статус интеграций отображается честно.

## Первые задачи

- Согласовать дизайн главного экрана и сценарий.
- Согласовать API Go и формат `session_id`, результатов, опросов и измерений с временем, единицами и источником.
- Проверить взаимодействие Godot → Go → хранилище → ответ.
- Получить один реальный показатель часов и один ответ имеющейся локальной модели.
- Подготовить английское описание и ссылки на NASA.
- Перед защитой проверить Windows-сборку и автономный режим.
