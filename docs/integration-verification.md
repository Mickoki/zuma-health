# Проверка интеграции Zuma — 14 ноября 2026

Исходная ветка мини-игр: `feat/minigames-module`, commit `4a68aaa`.
Основное приложение сверено со снимком `snapshot/demo-app-2026-11-14`,
commit `4accabf`; итог опубликован в ветке
`codex/integrate-minigames` репозитория команды.

## Проверено

- Сервер: `go test ./...` — успешно; в том числе проверка опроса в игровом
  payload, неизменности данных при повторе и ошибки при конфликте. Отдельный
  тест с mock Ollama проверяет выбор факта опроса, обязательное ограничение
  о неизвестном времени заполнения и отказ от несуществующего факта для старых
  прохождений без опроса.
- Клиент: `python tests/run_client_integration.py <Godot console>` — успешно,
  включая проверку обзора, графика и страниц истории игр с тестовым API.
- `python tests/run_real_server_integration.py <Godot console> <server exe>` —
  успешно на отдельной временной SQLite-базе: четыре прерванных тестовых
  прохождения с копией опроса отправлены, отчёты получены. Отдельная проверка
  подтверждает, что недоступный адрес в очереди не блокирует рабочий адрес.
  Другая часть того же теста завершает все четыре игры через сигналы игровых
  кнопок в headless Godot, отправляет пять прохождений с опросом и проверяет
  отчёты и сравнение двух сопоставимых игр в пары. Это не проверка физических
  действий мышью или готового exe.
- Godot отрисовал меню и все четыре игровые сцены при 960×540; игровые поля и
  основные кнопки видимы. Это проверка отрисовки, а не четыре полных прохождения.
- Экспортирован Windows x86-64 клиент `Zuma-integrated.exe`. В его настоящем
  окне с отдельной тестовой базой созданы профиль и опрос, завершена игра
  «Математика», проверены отправка, история, обзор и точка графика опроса.
  Для проверки ошибки очередь содержала записи с недоступным адресом; после
  исправления запись для работающего сервера отправилась, неотправленные записи
  сохранились. Введённые значения и профиль были вымышленными.

Запускался сервер из `builds/windows/zuma-server.exe`, модель намеренно была
недоступна. Подготовлен `tests/run_model_integration.py` для повторной проверки
установленной Qwen на синтетической игре и временной базе; сам сценарий проверен
с локальной тестовой заменой Ollama. На текущем компьютере Ollama недоступна,
поэтому новая связка опроса с настоящей моделью здесь не подтверждена.
Визуальное прохождение остальных трёх игр и тест готового комплекта
на компьютере презентации остаются полезной финальной проверкой. Эта запись не
является подтверждением медицинской валидности или допуска к конкурсу.
